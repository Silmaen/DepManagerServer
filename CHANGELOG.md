# Changelog

All notable changes to this project are documented in this file.

## [1.4.1] — 2026-10-07

- Deprecate the project in favor of [Conan](https://conan.io): 1.4.1 is the final release.

## [1.4.0] — 2025-11-18

- Support YAML files as package definition.
- Support package dependencies.
- Add multilanguage support.
- Modernize the docker image backend and the web UI.
- Improve logging and fix security issues.

## [1.3.0] — 2025-06-17

- Add user management (list, create, delete, change password).
- Add package management in the UI (list, delete).
- Provide a basic server with package upload/download.
